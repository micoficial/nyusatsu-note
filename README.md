# 入札ノート

国・都道府県・市区町村の**入札公告**と、国の機関の**落札実績**を、発注機関・地域・分野・落札した会社ごとにまとめて無料で見せる静的サイトです。有料の入札情報サービスで見るような「どの会社が、どこから、いくらで落札したか」を、国のオープンデータから自動で作ります。

公開先：https://micoficial.github.io/nyusatsu-note/

## データ

| データ | 提供 | 使い方 |
|---|---|---|
| [官公需情報ポータルサイト 検索API](https://www.kkj.go.jp/s/)（[APIガイド](https://www.kkj.go.jp/doc/ja/api_guide.pdf)） | 中小企業庁 | 入札公告（件名・機関・公告日・元の公告のURL）。公告文から締切・開札の日付を読み取る |
| [調達ポータル 落札実績オープンデータ](https://www.p-portal.go.jp/pps-web-biz/UAB02/OAB0201)（年度ごとの全件ZIP＋日ごとの差分ZIP） | デジタル庁 | 国の機関の落札（件名・落札日・落札額・府省・落札者・法人番号） |

- 調達ポータルは政府標準利用規約（第2.0版）準拠・CC BY 4.0互換。出典と「加工して作成」の記載が必要（全ページのフッターに入れている）。国が作成したように見せないこと
- 官公需ポータルのAPIは、利用規約で「APIを使っている旨の明記」と「同サイトへのリンク」が条件。大量に続けて送らないこと（`fetch.mjs` は4秒おきに1回）
- どちらも GitHub Actions（海外）から取れる（2026-10-23 に確認）

## 動かし方

```bash
node scripts/fetch.mjs                 # 調達ポータル＋公告の直近3日（日曜は30日）を data/ に取る
KKJ_DAYS=95 node scripts/fetch.mjs     # 公告を95日さかのぼって取る（初回）
node scripts/build.mjs                 # dist/ にサイトを作る（1分ほど）
node scripts/serve.mjs                 # http://localhost:4177/nyusatsu-note/ で確認
```

`LIMIT=300 node scripts/build.mjs` で会社ページを300件だけ作れる（試すとき用）。`KEEP_RAW=1` で官公需ポータルの応答を `data/raw/kkj/` に残し、`REUSE_RAW=1` で残した応答を読み直す（取り直さない）。

## 仕組み

- `scripts/fetch.mjs`：取得。調達ポータルは一覧ページからファイル名を読み、全件ZIP（月1回更新）と差分ZIP（毎日）を取る。官公需ポータルは公告日1日ずつ全都道府県をまとめて取り、1000件を超えたり応答がなかったりしたら都道府県で分けて取り直す。公告は月ごとの JSON（`data/store/kkj/`）に貯め、400日より古いものは捨てる
- `scripts/lib/kkj.mjs`：APIのXMLを読む。件名の掃除（「126145.pdf」のようなファイル名だけのときは公告文から件名を探す）、公告文から締切・開札の日付を読み取る（いちばん遅い日付。読み取った文も残す）
- `scripts/lib/load.mjs`：落札実績のCSVを読む。8列でなければ止まる（黙って変な値を出さない）。件名が「テスト」「ダミーデータ」のものは外す
- `scripts/lib/meta.mjs`：府省等のコード（S1＝国土交通省など。コード表が公開されていないので件名から判定）、分野（件名の語で分ける）、売払い・単価のコード
- `scripts/build.mjs` と `scripts/pages/`：会社（法人番号ごと）・府省・分野・ランキング・機関（公告）・都道府県・日付などのページ
- `.github/workflows/deploy.yml`：毎日 21:30 と 6:40（日本時間）に、リリース `data-latest` の控え（貯めた公告・調達ポータルのZIP）を戻し、新しい分を取り、控えを差し替えてから作り直して GitHub Pages に出す。`data/summary.json` を毎回コミットするので、定期実行が60日で止まることもない
- 国のサイトに海外から届かなくなったときは、このPCで `GH_TOKEN=... bash scripts/refresh-data.sh` を実行すると、日本の回線で取って控えを差し替え、作り直しを始める

## 注意

- 締切・開札の日付は、公告文から自動で読み取った目安（官公需ポータルのデータには締切日の項目がほとんど入っていない）。ページには必ず元の公告へのリンクと、読み取った文を出している
- 落札実績は国の機関（府省）が政府電子調達システムで行ったものだけ。自治体・独立行政法人の落札結果は含まない
- 落札額の合計から、売払い（方式コード8002020）と単価だけが記録されたもの（8002050）を外している。複数年度の契約は落札した年度にまとめて入る
- 会社は法人番号で集計（社名が変わっても1ページ）。法人番号のない事業者（個人事業主など）は会社ページを作らない
